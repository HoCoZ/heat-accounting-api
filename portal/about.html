О системе АСУ «Теплоснабжение»

Архитектура, технологии и команда разработки

Архитектура системы

Трёхуровневая архитектура на базе виртуализации Oracle VirtualBox

🖥️

Сервер приложений

VM1-Server — Ubuntu Server 22.04, FastAPI + PostgreSQL 17. Обрабатывает запросы REST API и хранит данные.

👤

Рабочее место диспетчера

VM2-Dispatcher — Ubuntu Desktop 22.04. Доступ к мониторингу и управлению через веб-интерфейс.

🔧

Рабочее место администратора

VM3-Admin — Ubuntu Desktop 22.04. Администрирование БД и анализ данных через DBeaver.

Стек технологий

🐍

Python 3.11 + FastAPI

Асинхронный веб-фреймворк для построения высокопроизводительного REST API.

🗄️

PostgreSQL 17

Реляционная база данных для хранения информации об абонентах и показаниях.

📊

HTML5 + CSS3 + JavaScript

Клиентский веб-интерфейс с адаптивным дизайном и динамической визуализацией.

🔧

Oracle VirtualBox 7

Среда виртуализации для развёртывания многомашинного стенда АСУ.
